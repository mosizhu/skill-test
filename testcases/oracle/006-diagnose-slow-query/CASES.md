## 测试目标

验证对已知慢查询的诊断完整性和准确性。

## 前置条件

- oracle-rac_node01 实例运行正常
- AWR 或 v$sql 中有可诊断的查询

## 执行步骤

1. 通过 Mopheus 工单触发 `db-oracle-diagnose-slow-query` skill
2. 传入参数:
   - `instance_host` = `oracle-rac_node01`
   - `sql_text` = 一个已知执行较慢的查询 SQL（如包含大表 JOIN 的查询）
   - `execution_plan` = true（要求输出执行计划）
   - `top_n_events` = 5
3. 等待诊断完成
